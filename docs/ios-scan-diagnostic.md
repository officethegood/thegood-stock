# 🔍 ทดสอบ + เก็บข้อมูลปัญหาสแกน QR ถัง O2 บน iPhone

> สำหรับทีมที่มี **iPhone** ช่วยทดสอบให้หน่อย — ทีมพัฒนาไม่มีเครื่อง iOS เลยต้องขอข้อมูลจากหน้างานจริง
> ใช้เวลา ~3 นาที ทำตามทีละขั้น แล้วส่ง **ภาพถ่ายหน้าจอ** กลับมา

---

## ขั้นที่ 0 — อัปเดตเวอร์ชันก่อน (สำคัญมาก)

ระบบฝังแคชไว้ในเครื่อง ต้องล้างก่อนไม่งั้นจะเทสของเก่า:

1. iPhone → **ปิดแท็บ** Safari ที่เปิดเว็บนี้อยู่ทั้งหมด
2. Settings (ตั้งค่า) → Safari → เลื่อนลง → **"Clear History and Website Data" (ล้างประวัติฯ)** → ยืนยัน
3. เปิด Safari ใหม่ → เข้าเว็บ → login

> ถ้าไม่อยากล้างทั้งหมด: เปิดแบบ **ไม่ระบุตัวตน (Private)** แทน ก็ได้ของใหม่เหมือนกัน

---

## ขั้นที่ 1 — ลองสแกนปกติก่อน

1. เข้าหน้า **O2 → สแกนถัง** → กดเปิดกล้อง → จ่อ QR ถัง ~5 วินาที
2. **อ่านได้ไหม?** จดไว้: ได้ / ไม่ได้

ถ้า **อ่านได้แล้ว** 🎉 → จบ แจ้งทีมว่า "เวอร์ชันใหม่สแกนได้แล้ว" ไม่ต้องทำขั้นต่อไป

ถ้า **ยังไม่ได้** → ทำขั้นที่ 2 ต่อ (เก็บข้อมูลให้ทีมแก้)

---

## ขั้นที่ 2 — เปิดโหมดวิเคราะห์ (ถ้ายังสแกนไม่ได้)

1. ที่ช่อง URL ของ Safari ต่อท้ายที่อยู่เว็บด้วย **`?scandebug=1`**
   - ตัวอย่าง: `https://officethegood.github.io/thegood-stock/staff-oxygen.html?scandebug=1`
   - ⚠️ ถ้าที่อยู่มี `?` อยู่แล้ว ให้ใช้ `&scandebug=1` แทน
2. กด Enter โหลดหน้าใหม่ → เข้าหน้า O2 → สแกนถัง → กดเปิดกล้อง → จ่อ QR ค้างไว้ ~10 วินาที
3. จะมี **กล่องข้อความสีเขียวเล็กๆ มุมล่างซ้าย** ขึ้นมา (ตัวช่วยวิเคราะห์)
4. **ถ่ายรูปหน้าจอ** ให้เห็นกล่องเขียวนั้นชัดๆ → ส่งกลับทีม

> กล่องเขียวจะบอกประมาณนี้:
> ```
> path=FALLBACK (html5-qrcode) — loading lib…
> fallback: lib loaded
> fallback: h5q.start ok (full-frame)
> fallback: scanning… (30 frames, no code yet)
> ```
> หรือถ้ามี error ก็จะขึ้น `ERROR: ...` — ทีมต้องการเห็นบรรทัดพวกนี้

---

## ขั้นที่ 3 — ข้อมูลเสริม (ช่วยได้มาก)

ส่งมาด้วยถ้าทราบ:
- [ ] iPhone รุ่นอะไร + **iOS เวอร์ชันอะไร** (Settings → General → About → Software Version)
- [ ] หน้า **เบิกของ** บน iPhone เครื่องเดียวกัน สแกนได้ไหม (ได้ / ไม่ได้)
- [ ] ใช้ **Safari** หรือเปิดผ่านแอปอื่น (LINE / Chrome / ฯลฯ)
- [ ] ตอนกดเปิดกล้อง มันถาม **อนุญาตใช้กล้อง** ไหม แล้วกดอนุญาตหรือยัง

---

## สรุปสิ่งที่ต้องส่งกลับ

1. ✅/❌ ขั้นที่ 1 สแกนได้ไหม
2. 📷 รูปถ่ายหน้าจอกล่องเขียว (ขั้นที่ 2) — ถ้ายังไม่ได้
3. 📝 ข้อมูลเครื่อง + iOS เวอร์ชัน (ขั้นที่ 3)

เท่านี้ทีมพัฒนาจะรู้สาเหตุชัดเจนและแก้ได้ในรอบเดียว 🙏
