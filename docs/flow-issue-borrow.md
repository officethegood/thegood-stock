# Flow การเบิก – ยืม – ย้าย – กระเป๋า (Thegood Stock)

> อัปเดต 2026-07-10 (v0.20.35) — เขียนตามที่ตกลงกับคุณ Chittawan:
> กระเป๋ายืมขึ้นรถได้, ของย้ายลงกระเป๋าได้, การยืมระบุจุดประสงค์ได้

ทุก flow อยู่ที่หน้า **สแกนเบิก-จ่าย (staff-scan.html)** ยกเว้นที่ระบุไว้

---

## 1. เลือก flow ไหนดี? (ตารางตัดสินใจ)

| สถานการณ์ | ใช้ flow | ผลกับสต็อก |
|---|---|---|
| หยิบของไปใช้ **ไม่คืน** (ยา, ของสิ้นเปลือง) | **เบิก-จ่าย** | ตัดสต็อกถาวร |
| หยิบอุปกรณ์ไปใช้ **แล้วจะคืน** (เครื่องมือ, เครื่อง O2) | **ยืม-คืน › ยืมอุปกรณ์** | ตัดสต็อกชั่วคราว + สร้างรายการยืม มีกำหนดคืน |
| เอาของจากชั้นเก็บ **ใส่ลงกระเป๋า** (จัด ALS bag) | **ย้ายของ (Transfer)** | ของยังอยู่ในคลัง แค่เปลี่ยนตำแหน่ง |
| เอา **ทั้งกระเป๋า** ขึ้นรถ | **สแกนกระเป๋า › เอากระเป๋าขึ้นรถ** | ของในกระเป๋าตามไปทั้งใบ ไม่มีกำหนดคืน |
| เอากระเป๋าลงจากรถกลับที่เก็บ | **สแกนกระเป๋า › คืนกระเป๋า** | กลับที่เก็บเดิมอัตโนมัติ |

**คำตอบคำถามคุณ Chittawan:** จะเบิกใช้ทั้ง ALS bag →
**ไม่ต้องยืมรายชิ้น** ให้ (1) ย้ายของลงกระเป๋าครั้งเดียวตอนจัดกระเป๋า
(2) หลังจากนั้นสแกนกระเป๋าแล้วกด "เอากระเป๋าขึ้นรถ" ได้เลย ของทั้งใบตามไปเอง

## 2. เบิก-จ่าย (ของใช้แล้วหมดไป)

แท็บ **เบิก-จ่าย** (ค่าเริ่มต้นของหน้า)

1. สแกน/พิมพ์ **สินค้า** (SKU/บาร์โค้ด)
2. สแกน/พิมพ์ **ตำแหน่ง** ที่หยิบของ
3. ถ้าเป็นของคุมล็อต → เลือก **ล็อต** (เรียง FEFO — หมดอายุก่อนขึ้นก่อน,
   เลือกข้ามล็อตจะมีคำเตือน)
   - ⭐ **ล็อตหมดอายุ เบิกได้** แต่ต้องผ่านหน้าต่างยืนยันสีแดง + พิมพ์เหตุผล
     (เช่น ใช้ฝึกซ้อม / ส่งทำลาย) — เหตุผลถูกบันทึกลงประวัติ
     **ห้ามใช้กับผู้ป่วยเด็ดขาด** และของหมดอายุยัง **ยืม/ย้ายไม่ได้**
   - ล็อตที่**ถูกเรียกคืน (recall)** ยังห้ามเบิกเด็ดขาดทุกกรณี
4. ใส่ **จำนวน** + ประเภท (เบิกใช้ / ตัดของเสีย) + หมายเหตุ → **บันทึก**

หลังสแกนสินค้าแล้ว ระบบจะถามด้วยว่า **"ต้องการย้ายสินค้าไปตำแหน่งอื่นหรือไม่?"**
→ นี่คือทางเข้า flow ย้ายของ (ข้อ 4)

---

## 3. ยืม-คืน (อุปกรณ์ที่ต้องคืน)

แท็บ **ยืม-คืน**

### 3.1 ยืมอุปกรณ์ (5 ขั้น)

1. **สแกนสินค้า** — ถ้าไม่มีของเหลือในคลัง ระบบบอกทันที
   - ของคุมล็อต (เช่น paddle AED) → เลือกล็อตก่อน (FEFO)
   - ⭐ สแกนรหัส **BAG-…** ตรงนี้ → ระบบเปิด **หน้ากระเป๋า** ให้อัตโนมัติ
     (ยืมกระเป๋า = เอาขึ้นรถ ดูข้อ 5)
2. **สแกนตำแหน่ง** — ระบบโชว์ปุ่ม "ของอยู่ที่ — แตะเพื่อเลือก" ให้เลย
   (เลือกตำแหน่งที่ไม่มีของ ระบบปฏิเสธทันที ไม่รอตายตอนยืนยัน)
3. **กำหนดวันคืน + จำนวน + จุดประสงค์** ⭐ ใหม่
   - วันคืน: 1 / 3 / 7 วัน หรือกำหนดเอง (ค่าเริ่มต้น 3 วัน)
   - **ยืมไปทำอะไร?** เลือกอย่างใดอย่างหนึ่ง:
     - 🧰 **งานทั่วไป / สแตนด์บาย** — ใส่ชื่องานได้ (ไม่บังคับ)
     - 🚑 **ขึ้นประจำรถ** — ต้องแตะเลือกรถ (รายชื่อรถจากระบบ)
4. **ถ่ายรูป** ก่อนยืม (ไม่บังคับ — ข้ามได้)
5. **ยืนยัน** — สรุป สินค้า/ตำแหน่ง/ล็อต/จำนวน/จุดประสงค์/กำหนดคืน

จุดประสงค์ถูกบันทึกในหมายเหตุของรายการยืม เช่น
`ยืมขึ้นประจำรถ: TG3 | เอาไปแทนตัวที่เสีย` — Admin เห็นในหน้ารายการยืม

### 3.2 คืนอุปกรณ์ (3 ขั้น)

1. **สแกนสินค้า** ที่จะคืน → ระบบหารายการยืมค้างของเรา
   (มีหลายรายการ → เลือก; ยืมโดยคนอื่น → แจ้ง Admin)
   - ⭐ สแกนรหัส **BAG-…** → เปิดหน้ากระเป๋า ใช้ปุ่ม "คืนกระเป๋า" แทน
2. **ถ่ายรูป** ตอนคืน (ไม่บังคับ)
3. **ยืนยันคืน** — สต็อกกลับเข้าตำแหน่งเดิม, ล็อต (ถ้ามี) คืนยอดให้อัตโนมัติ

เลยกำหนดคืน → รายการขึ้นสถานะ **เลยกำหนด** และแจ้งเตือนทาง Telegram (cron)

## 4. ย้ายของ (Transfer) — รวมถึงย้ายลงกระเป๋า

ทางเข้า: โหมด **เบิก-จ่าย** → สแกนสินค้า → ปุ่ม **"ย้าย (Transfer)"**
(หรือหน้า คลัง › สินค้า สำหรับ Admin)

1. เลือก **ล็อต** (ถ้าเป็นของคุมล็อต)
2. เลือก **ต้นทาง** — สแกน QR หรือเลือกจากรายการ (เจาะถึงระดับล่างสุด)
3. เลือก **ปลายทาง** — สแกน QR กระเป๋า หรือเลือก **กระเป๋า (BAG-…)** จากรายการได้เลย
4. ใส่จำนวน → **ยืนยันการย้าย**

ใช้จัดกระเป๋า: ย้าย `Stock/ชั้นเก็บ → BAG-ALS-001` ของจะไปโผล่ใน
เช็คลิสต์ของกระเป๋า และตามกระเป๋าไปเมื่อกระเป๋าขึ้นรถ

---

## 5. กระเป๋าขึ้นรถ / คืนกระเป๋า

ทางเข้า: สแกน QR กระเป๋า (โหมดเบิก-จ่าย **หรือ** พิมพ์/สแกนในยืม-คืนก็ได้ — ระบบ route ให้)

หน้ากระเป๋าแสดง: เช็คลิสต์ของในกระเป๋า (ครบ/ขาด/หมดอายุ) + ปุ่มตามสถานะ:

- กระเป๋าอยู่ที่เก็บ → **"เอากระเป๋าขึ้นรถ"** → เลือกรถ → เสร็จ
  (ระบบจำที่เก็บเดิมไว้ให้)
- กระเป๋าอยู่บนรถ → **"คืนกระเป๋าเข้าที่เก็บเดิม"** → กดปุ่มเดียวกลับที่เดิม

ไม่มีกำหนดคืน (ตั้งใจออกแบบ — เป็นการย้ายบ้านชั่วคราว ไม่ใช่การยืม)
ทุกครั้งบันทึกลง **ประวัติกระเป๋า** (คลัง › ประวัติ › กระเป๋า) + แจ้ง Telegram

## 6. ภาพรวม (แผนผัง)

```
สแกนรหัส ──┬─ สินค้า ─┬─ เบิก-จ่าย ────── ตัดสต็อกถาวร
           │          ├─ ยืมอุปกรณ์ ───── ตัดชั่วคราว + กำหนดคืน + จุดประสงค์ (ทั่วไป/ขึ้นรถ)
           │          └─ ย้าย (Transfer) ─ เปลี่ยนตำแหน่ง (เช่น ลงกระเป๋า)
           │
           └─ กระเป๋า (BAG-…) ─ หน้ากระเป๋า ─┬─ เอากระเป๋าขึ้นรถ (ของตามไปทั้งใบ)
                                             └─ คืนกระเป๋าเข้าที่เก็บเดิม
```
