# BUG-0.7-T203-01 — staff-print.html always redirects to 403 for all users

**Date:** 2026-05-19
**Severity:** High
**Blocking:** T203, T204, T207, T208 (4 tests) — QR print page inaccessible to all users
**Found by:** QA (Run 2 live functional test @ aefa347)
**Owner:** FE agent
**Status:** Open

---

## Title

`requireRole(['Admin','Employee'])` in `js/staff-print.js` always redirects to 403 because `shared/auth.js:requireRole` only accepts a string, not an array

---

## Steps to Reproduce

1. Log in as Admin (role="Admin")
2. Navigate to https://officethegood.github.io/thegood-stock/staff-print.html
3. Page immediately redirects to https://officethegood.github.io/thegood-stock/403.html

Also reproducible as Employee (role="Employee") — same result.

**Cold cache:** same result  
**Warm cache:** same result

---

## Expected

staff-print.html loads for both Admin and Employee roles (as documented in `js/staff-print.js` comment line 4: "Access: Employee + Admin").

---

## Actual

All users (Admin and Employee) are redirected to 403 "ไม่มีสิทธิ์เข้าถึงหน้านี้".

---

## Environment

- Browser: Chrome desktop (Thegood browser)
- OS: Windows 11 Pro 10.0.26200
- Viewport: 1278×1270
- URL: https://officethegood.github.io/thegood-stock/staff-print.html
- Commit: aefa347 (feat(phase0.7-fe): transfer modal + scanner fallback + bin/zone QR)
- Auth: Admin role, `stock_access_token` present in localStorage

---

## Root Cause

`js/staff-print.js` line 46:

```javascript
window.requireRole(['Admin', 'Employee']);  // passes an ARRAY
```

`shared/auth.js` line 109–114:

```javascript
function requireRole(role) {
  if (getUserRole() !== role) {   // strict equality: "Admin" !== ['Admin','Employee'] → always true
    window.location.replace('./403.html');
    return false;
  }
  return true;
}
```

The function was designed for a single-string argument (used in `js/admin-shell.js` as `requireRole('Admin')`). When `staff-print.js` passes an array, the `!==` comparison always fails regardless of the user's actual role.

---

## Fix

`shared/auth.js` — update `requireRole` to accept string or array:

```javascript
function requireRole(role) {
  const allowed = Array.isArray(role) ? role : [role];
  if (!allowed.includes(getUserRole())) {
    window.location.replace('./403.html');
    return false;
  }
  return true;
}
```

This is backward-compatible — `requireRole('Admin')` still works as before.

---

## Regression Risk

Low. `admin-shell.js` uses `requireRole('Admin')` — unchanged behavior after fix. Only `staff-print.js` uses the array form.
