## A. ถังออกซิเจน — สถานะใหม่ "รอส่งเติม"

ระบบเพิ่มสถานะใหม่ในเส้นทางถัง O2:
`ประจำรถ → รอส่งเติม (ลงมากองรอที่ฐาน) → กำลังเติม (ส่งร้าน) → พร้อมใช้`

### A1 — เส้นทางเต็ม (ทำโดย staff)
- [ ] สแกนถังสถานะ **ประจำรถ** → เลือกการ์ด **"⬇️ ลงรอเติม"**
- [ ] ขั้นเลือกสถานที่ขึ้นข้อความ **"วางที่กองรอไหน?"** → เลือกที่ → ยืนยัน
- [ ] **ผลที่ควรได้:** ถังเปลี่ยนเป็น **รอส่งเติม** (ป้ายสีเหลือง) + Telegram เด้งข้อความ **"⬇️ ลงรอเติม"**
- [ ] สแกนถังเดิม (รอส่งเติม) → เลือก **"🚚 ส่งร้าน"** → เลือกร้าน → ยืนยัน
- [ ] **ผลที่ควรได้:** ถังเปลี่ยนเป็น **กำลังเติม** (ป้ายสีฟ้า) + Telegram เด้ง **"🚚 ส่งร้าน"**

### A2 — สิทธิ์ staff กับ admin (ถังสถานะ "รอส่งเติม")
- [ ] **staff** สแกนถังรอส่งเติม → เห็นการ์ด **"🚚 ส่งร้าน" อย่างเดียว**
- [ ] **admin** เปิดถังรอส่งเติม → เห็น **"🚚 ส่งร้าน" + "↩️ ยกเลิกรอเติม"**
- [ ] **ผลที่ควรได้:** staff ต้อง **ไม่เห็น** "ยกเลิกรอเติม"

### A3 — 🟠 ปุ่ม "กลับ" ต้องไม่ทำสถานที่ที่เลือกหาย
- [ ] staff สแกนถัง **ประจำรถ** → "⬇️ ลงรอเติม" → เลือกสถานที่ → ไปขั้นถัดไป (ใส่หมายเหตุ)
- [ ] กดปุ่ม **"กลับ"**
- [ ] **ผลที่ควรได้:** กลับมาที่ **ขั้นเลือกสถานที่** พร้อมสถานที่เดิมที่เลือกไว้ (ห้ามเด้งข้ามไปขั้นเลือกการกระทำ)
- [ ] ลองซ้ำกับ **"🚚 ส่งร้าน"** และ **"⛽ ส่งเติม"** — ต้องกลับมาขั้นเลือกสถานที่ทุกครั้ง

### A4 — หน้าหลักแสดง 6 สถานะ
- [ ] หน้าหลัก → ช่อง "สถานะถังออกซิเจน"
- [ ] **ผลที่ควรได้:** เห็น 6 ป้าย เรียงลำดับ: พร้อมใช้ → ประจำรถ → **รอส่งเติม** → กำลังเติม → ซ่อมบำรุง → ปลดระวาง

### A5 — 🔴 แจ้งเตือนรวมส่งร้าน (ทำหลัง apply migration ฐานข้อมูลแล้วเท่านั้น)
- [ ] admin → ตั้งค่า → ตั้ง **เกณฑ์แจ้งเตือนถังรอเติม = 2** (ชั่วคราว)
- [ ] ทำถังเข้าสถานะ **รอส่งเติม** ให้ครบ 2 ถัง
- [ ] **ผลที่ควรได้:** ถังตัวที่ 2 (ตัวที่ทำให้ครบเกณฑ์) เปลี่ยนสถานะ **สำเร็จ ไม่ขึ้น error** + Telegram เด้ง **"ถังรอส่งเติม 2 ถัง — รวบส่งร้านได้แล้ว"**
- [ ] ตั้งค่าเกณฑ์กลับเป็น **5**
- [ ] *(หมายเหตุ: ก่อนแก้บั๊กนี้ การเปลี่ยนสถานะถังตัวที่ครบเกณฑ์จะ error และถังไม่เปลี่ยนสถานะ)*

## B. แจ้งเตือน Telegram — แสดงชื่อสถานที่

### B1 — ชื่อสถานที่แทนรหัส
- [ ] เบิกของ 1 รายการ จากสถานที่ที่ตั้ง "ชื่อ" ไว้
- [ ] **ผลที่ควรได้:** Telegram แสดง **ชื่อสถานที่** (เช่น "ชั้น A-5") ไม่ใช่รหัส (เช่น "STG-A-5")
- [ ] สถานที่ที่ไม่ได้ตั้งชื่อ → ยังแสดงเป็นรหัสตามเดิม (ปกติ)

## C. คลัง — หน้า "ผ้า" และเมนูย่อย

### C1 — หน้าผ้า
- [ ] คลัง → กดปุ่ม **"ผ้า"** (ปุ่มที่ 2)
- [ ] **ผลที่ควรได้:** เห็นตารางตรวจนับผ้า + ปุ่มหมวดย่อย (ผ้าปู/ผ้าห่ม/ผ้าขนหนู/...) + **ไม่มี** ช่องเลือกหมวด (ถูกซ่อนเพราะล็อกเป็นผ้าแล้ว)
- [ ] กดปุ่ม "สินค้า" → กลับโหมดปกติ ช่องเลือกหมวดโผล่กลับมา
- [ ] สลับ ผ้า ↔ สินค้า ไปมา 4–5 รอบ → **หัวตารางตรงกับข้อมูลทุกครั้ง ไม่เพี้ยน**

### C2 — เมนูย่อยครบ 5 ปุ่ม
- [ ] คลัง → เห็นปุ่ม: **สินค้า │ ผ้า │ ถังออกซิเจน │ ALS Bags │ ประวัติ**
- [ ] กดวนทุกปุ่ม → แต่ละหน้ามีเนื้อหา ไม่มีหน้าว่าง มีปุ่มไฮไลต์ทีละอัน

### C3 — 🟡 ลิงก์จากหน้าหลักหลังรีเฟรช
- [ ] เปิดหน้า "ผ้า" ค้างไว้ (ให้ระบบจำ)
- [ ] **ปิด-เปิดเว็บใหม่** (หรือรีเฟรชแบบไม่ใช้แคช)
- [ ] ไปหน้าหลัก → กดลิงก์สินค้าใกล้หมด "→ ดู" หรือ "ดูทั้งหมด"
- [ ] **ผลที่ควรได้:** เข้า คลัง › สินค้า โดยช่องเลือกหมวดโผล่ ตารางปกติ (ไม่ว่าง ไม่เพี้ยน) — ลอง 4–5 รอบ

## D. หน้าหลัก — ลิงก์ลัด

### D1 — ลิงก์เด้งเข้าถูกหน้า
- [ ] ออกซิเจน "ดูทั้งหมด →" → เข้า คลัง › ถังออกซิเจน
- [ ] ผ้า "ดูทั้งหมด →" / "ดูรายละเอียด → ผ้า" → เข้า คลัง › **ผ้า** (เห็นตารางผ้าเลย)
- [ ] ALS Bags (กดป้ายตัวเลข) → เข้า คลัง › ALS Bags
- [ ] สินค้าใกล้หมด / ล็อตยา "→ ดู" → เข้า คลัง › สินค้า (มีการกรอง/ค้นหา)

---

## E. หน้า "ประวัติ" การเคลื่อนไหว

### E1 — แสดงผล + การกรอง
- [ ] คลัง → ประวัติ → เห็นตารางรายการล่าสุด (เวลา / ชนิด / สินค้า / จำนวน± / สถานที่ / ผู้ทำ / เหตุผล)
- [ ] เลือกชนิด **"เบิก"** → เหลือเฉพาะการเบิก
- [ ] เลือก **สถานที่** → กรองถูกต้อง
- [ ] ตั้ง **ช่วงวันที่ (ตั้งแต่–ถึง)** → แสดงตามช่วง (รวมรายการช่วงท้ายของวันด้วย)
- [ ] พิมพ์ **ค้นหาสินค้า** (SKU หรือ ชื่อ) → กรองทันที
- [ ] กด **"โหลดเพิ่ม"** → ได้อีก 50 แถว

### E2 — กรณีตั้งวันกลับด้าน (รู้ไว้ ไม่ใช่บั๊ก)
- [ ] ตั้ง "ถึง" ก่อน "ตั้งแต่" → ขึ้น "ไม่พบรายการ" (ระบบยังไม่เตือนว่าช่วงวันกลับด้าน — ทราบไว้)

## F. การสแกน (ทดสอบทั้ง iPhone และ Android)

### F1 — 🔴 iPhone สแกนหน้าถัง O2 (บั๊กที่เพิ่งแก้)
- [ ] **iPhone (Safari)** → หน้าสแกนถังออกซิเจน → เปิดกล้อง → จ่อ QR ถัง
- [ ] **ผลที่ควรได้:** **อ่านได้** (ก่อนแก้: iPhone อ่าน QR หน้านี้ไม่ได้)

### F2 — iPhone สแกนหน้าเบิก
- [ ] iPhone → หน้าเบิก → สแกนบาร์โค้ดสินค้า แล้วสแกน QR สถานที่
- [ ] **ผลที่ควรได้:** อ่านได้ทั้งสองอย่าง

### F3 — Android (เช็คว่าไม่พัง)
- [ ] **Android (Chrome)** → ทั้งหน้า O2 และหน้าเบิก → ยังสแกนได้ปกติ

### F4 — 🟠 ข้อความ error ต้องไม่ท่วมจอ (บั๊กที่แก้)
- [ ] หน้าเบิก → จ่อ QR ที่ไม่มีในระบบ (เช่น QR สติกเกอร์ทั่วไป) ค้างไว้ ~5 วินาที
- [ ] **ผลที่ควรได้:** ขึ้น "ไม่พบสินค้านี้" **ครั้งเดียวต่อ ~2.5 วินาที** (ไม่ขึ้นเป็นสิบรัวๆ)
- [ ] จ่อ QR สินค้าจริงทันที → อ่านติดเฟรมแรก
- [ ] กด "สแกนใหม่" แล้วจ่อ QR เดิมซ้ำ → อ่านได้ทันที (ไม่ถูกบล็อก)
